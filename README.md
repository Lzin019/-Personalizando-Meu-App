# 📱 Projeto Luiz

> Projeto desenvolvido como vitrine de componentes visuais e base de estudos para as aulas de desenvolvimento mobile do curso Codeverse.

---

## 🎯 Sobre o Projeto

Este aplicativo foi criado a partir da CLI `create-codeverse-mobile` e totalmente personalizado para refletir minha identidade visual. Ele serve tanto como um portfolio de componentes nativos quanto como estrutura inicial reutilizável para a evolução das próximas atividades do curso.

---

## ✨ Funcionalidades da Tela "Sobre"

A interface principal foi construída com componentes totalmente estilizados e modulares:

* **Header Customizado:** Cabeçalho de boas-vindas contendo título principal e subtítulo descritivo.
* **Foto de Perfil:** Componente de imagem configurado com bordas arredondadas/avatar.
* **Cards de Informação (2x):**
  * **Card 1 - Bio/Perfil:** Breve resumo sobre mim e meus objetivos no programa.
  * **Card 2 - Habilidades & Interesses:** Destaque de tecnologias e áreas de estudo.
* **Botões Estilizados (2x):**
  * **Botão Primário:** Ação principal (ex: *Contatar* / *Ver Portfólio*).
  * **Botão Secundário:** Estilo *Outlined* ou variante para ações alternativas.

---

## 🎨 Personalização & Identidade Visual

- [x] **Palette de Cores:** Alteração do tema padrão para cores personalizadas.
- [x] **Tipografia & Textos:** Textos adaptados para contextualizar o perfil do desenvolvedor.
- [x] **Logotipo:** Inclusão de logo/marca própria na estrutura base.
- [x] **Organização:** Código refatorado em componentes reutilizáveis para manutenibilidade nas próximas aulas.
